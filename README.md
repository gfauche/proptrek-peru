# PropTrek Perú — Mapa Interactivo de Proyectos Inmobiliarios y Score Card Urbano

Plataforma interactiva geoespacial de análisis inmobiliario, comercial y de inclusión financiera en el Perú.

## 🚀 Acceso Web Perpetuo
- **Mapa y Score Card Directo:** [https://gfauche.github.io/proptrek-peru/](https://gfauche.github.io/proptrek-peru/)
- **Portal Bento Grid:** [https://gfauche.github.io/proptrek-peru/bento.html](https://gfauche.github.io/proptrek-peru/bento.html)

## 🎯 Capacidades Clave
1. **Radar Score Card (/100):** Algoritmo ponderado de atractivo comercial, caminabilidad y equipamiento urbano (Malls, Comercio Ancla, Red Financiera y Oferta Residencial).
2. **Buffer de Proximidad:** Isócronas y radios de influencia (300m, 500m, 1km, 2km).
3. **Vitrina de Proyectos:** Precios en USD/PEN, precio por m², unidades disponibles y contacto con promotores.
4. **Diseño Responsive:** Optimizado para escritorio, tablets y teléfonos móviles.
